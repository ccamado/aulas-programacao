O problema
Guardar 5 notas — como fazer?
❌ Jeito difícil — sem lista
# 5 variáveis separadas... imagine 100! nota1 = 7.0 nota2 = 8.5 nota3 = 5.0 nota4 = 9.0 nota5 = 6.5 media = (nota1+nota2+nota3+ nota4+nota5) / 5
✅ Jeito certo — com lista
# Tudo numa só variável! notas = [7.0, 8.5, 5.0, 9.0, 6.5] media = sum(notas) / len(notas) print(media) # 7.2
Lista: uma variável que guarda vários valores em sequência!

# Acessar pelo índice notas = [7.0, 8.5, 5.0, 9.0, 6.5] print(notas[0]) # 7.0 (primeiro) print(notas[2]) # 5.0 (terceiro) print(notas[-1]) # 6.5 (último) print(notas[-2]) # 9.0 (penúltimo) # Fatia (slice) print(notas[1:3]) # [8.5, 5.0]
📌 Regra dos índices
  • Começa em 0, não em 1!
  • lista[0] → primeiro elemento
  • lista[-1] → último elemento
  • lista[-2] → penúltimo
  • lista[1:3] → do índice 1 até 2
Atenção: índice fora do tamanho da lista causa erro!
Operações com lista
sum, len, append — funções essenciais
# sum() — soma todos os valores notas = [7.0, 8.5, 5.0, 9.0, 6.5] print(sum(notas)) # 36.0 # len() — quantidade de itens print(len(notas)) # 5 # Calculando a média media = sum(notas) / len(notas) print(f"Média: {media:.1f}") # 7.2 # append() — adiciona ao final notas.append(10.0) print(notas) # [7.0, 8.5, 5.0, 9.0, 6.5, 10.0] # max() e min() print(max(notas)) # 10.0 print(min(notas)) # 5.0
📌 Resumo das funções
  • sum(lista) — soma os valores
  • len(lista) — conta os itens
  • lista.append(x) — adiciona no final
  • max(lista) — maior valor
  • min(lista) — menor valor
  • sorted(lista) — ordena (retorna nova lista)
Média sempre: sum(lista) / len(lista)
Percorrendo listas
for + if — analisar cada elemento
# Percorrer e exibir cada nota notas = [7.0, 8.5, 5.0, 9.0, 6.5] for nota in notas: print(nota)
# Contar aprovados (nota >= 6) aprovados = 0 for nota in notas: if nota >= 6: aprovados = aprovados + 1 print(f"Aprovados: {aprovados}")
# Exibir nota e situação for nota in notas: if nota >= 6: print(f"{nota} ✓ Aprovado") else: print(f"{nota} ✗ Reprovado")
📌 Como funciona o for
  • A cada volta, nota recebe um valor da lista
  • Começa pelo índice 0 e vai até o fim
  • O if dentro do for analisa cada elemento
  • O contador começa em 0 antes do for
  • Incrementar: x = x + 1 ou x += 1
Padrão clássico: contador = 0 → for → if → contador += 1 → print
