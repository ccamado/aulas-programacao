Passo 1

Uma ação do sistema pode virar uma função

def cadastrar_aviso(): print("\n--- CADASTRO DE AVISO ---")

Por que função?

Ela organiza uma ação do sistema em um bloco com nome claro.

Leitura

“Quando eu chamar cadastrar_aviso(), execute o cadastro.”

Onde essa função deve ser definida: antes ou dentro do while?

titulo = input("Título: ") data = input("Data: ") tipo = input("Tipo: ")
Teste: use um aviso realista, por exemplo: “Prova de Programação”, “03/09/2026”, “prova”.
Depois dos três input(), onde estão esses dados?
Passo 3

Um aviso pode ser representado por um dicionário

aviso = { "titulo": titulo, "data": data, "tipo": tipo }

Chaves

titulo, data e tipo identificam cada informação.

Valores

São os dados digitados pelo usuário.

Esse dicionário representa um aviso ou vários avisos?
Passo 4

Agora precisamos guardar o aviso na lista

avisos.append(aviso)
aviso = {...}

Ideia central: o dicionário representa UM aviso; a lista guarda VÁRIOS avisos.
Cadastre dois avisos e, temporariamente, use print(avisos) para conferir se ambos foram armazenados.

Central de Avisos — cadastro

Função organiza uma ação do programa.

Dicionário representa um aviso com pares chave:valor.

Lista guarda vários avisos.

append() adiciona um novo aviso à lista.

aviso = { "titulo": titulo, "data": data, "tipo": tipo } avisos.append(aviso)

Fluxo do cadastro: entrada → dicionário → append() → lista.
