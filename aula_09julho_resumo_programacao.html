Fechamento do Semestre:
Programação Aplicada I

Resumo geral para organizar no caderno o que foi estudado em Python.

Ideia central

Do código solto ao programa organizado

Programar é dividir um problema em partes menores, transformar essas partes em instruções e testar se o resultado faz sentido.

Resumo para o caderno: Programar é resolver um problema usando passos claros. Um programa organizado tem entrada de dados, processamento, decisão e saída.
Parte 1

Variáveis e entrada de dados

Variável

Guarda uma informação para ser usada depois.

input()

Recebe dados digitados pelo usuário, sempre como texto.

nome = input("Digite seu nome: ") idade = int(input("Digite sua idade: ")) O input recebe texto. Para fazer contas, usamos int() ou float().
Parte 2

Decisão com if/else

O if/else permite que o programa escolha caminhos diferentes de acordo com uma condição.

if media >= 6: print("Aprovado") else: print("Reprovado") A condição media >= 6 pode ser verdadeira ou falsa.
Parte 3

Funções: def, parâmetro e return

Funções organizam o código, evitam repetição e permitem reaproveitar uma solução.

def calcular_media(n1, n2): return (n1 + n2) / 2 resultado = calcular_media(7, 8) print(resultado) n1 e n2 são parâmetros. 7 e 8 são argumentos. return devolve o resultado.
Parte 4

Listas e dicionários

Listas guardam vários valores. Dicionários guardam dados identificados por nome, usando chave e valor.

notas = [7, 8, 6] media = sum(notas) / len(notas) aluno = { "nome": "Ana", "media": 7.5, "situacao": "Aprovada" }
Parte 5

Import e bibliotecas

O import permite usar bibliotecas do Python ou arquivos com funções criadas por nós.

import random numero = random.randint(1, 10) print(numero) Também podemos importar nossos arquivos: import funcoes
