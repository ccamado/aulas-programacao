Este é o ponto de partida da aula. Ele já possui o menu contínuo trabalhado anteriormente. Hoje vamos transformar a opção 1 - Cadastrar aviso em uma ação real.

Importante: não há solução completa nesta página. A função de cadastro será construída durante a aula.
# CENTRAL DE AVISOS — 27/08/2026 — 1º TEMPO
# Código inicial da aula

avisos = []

opcao = ""

while opcao != "0":
    print("\n========================")
    print("   CENTRAL DE AVISOS")
    print("========================")
    print("1 - Cadastrar aviso")
    print("2 - Listar avisos")
    print("0 - Sair")

    opcao = input("\nEscolha uma opção: ")

    if opcao == "1":
        print("\nCadastro ainda será implementado.")

    elif opcao == "2":
        print("\nListagem será implementada no 2º tempo.")

    elif opcao == "0":
        print("\nEncerrando...")

    else:
        print("\nOpção inválida.")

print("Central encerrada.")
