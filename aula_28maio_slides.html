Revisão · 14/05
Funções — organizar e reutilizar código
# Criando uma função def saudacao(nome): mensagem = "Olá, " + nome return mensagem resultado = saudacao("Ana") print(resultado) # Olá, Ana
# Função com cálculo def media(a, b): return (a + b) / 2 print(media(8, 6)) # 7.0
📌 Conceitos-chave
  • def — palavra que cria a função
  • parâmetro — variável na definição
  • argumento — valor passado na chamada
  • return — devolve o resultado
  • print — só exibe, não devolve
Regra: use return quando quiser usar o resultado depois!
Revisão · 21/05
Listas — vários valores em uma variável
# Criando uma lista notas = [7.0, 8.5, 6.0, 9.0, 5.5] # Acessando pelo índice print(notas[0]) # 7.0 (primeiro) print(notas[-1]) # 5.5 (último) # Funções úteis print(sum(notas)) # 36.0 print(len(notas)) # 5 media = sum(notas) / len(notas)
# Percorrendo com for + if for nota in notas: if nota >= 6: print(f"{nota} — Aprovado ✓")
📌 Operações com Listas
  • lista[0] — primeiro item
  • lista[-1] — último item
  • len(lista) — total de itens
  • sum(lista) — soma dos valores
  • lista.append(x) — adiciona item
  • for x in lista: — percorre tudo
  • lista[1:3] — fatia (slice)
Novo · 28/05
Dicionários — dados com nome (chave:valor)
📋 Lista — acessa por índice
aluno = ["João", 17, "3ºA"] # O que é aluno[1]? print(aluno[1]) # 17 # Difícil lembrar cada posição!
⚠️ Preciso memorizar o índice de cada dado
📚 Dicionário — acessa por nome
aluno = { "nome": "João", "idade": 17, "turma": "3ºA" } print(aluno["idade"]) # 17
✅ Cada dado tem um nome! Muito mais claro.
Dicionários · Operações
O que posso fazer com um dicionário?
# Criar aluno = {"nome": "Ana", "nota": 8.5} # Acessar print(aluno["nome"]) # Ana # Adicionar nova chave aluno["turma"] = "3ºA" # Atualizar valor existente aluno["nota"] = 9.0 # Remover del aluno["turma"] # Percorrer tudo for chave, valor in aluno.items(): print(chave, "→", valor)
📌 Métodos do dicionário
  • dic["chave"] — acessa valor
  • dic["chave"] = x — cria ou atualiza
  • del dic["chave"] — remove
  • dic.keys() — todas as chaves
  • dic.values() — todos os valores
  • dic.items() — pares chave/valor
  • "chave" in dic — verifica existência
Atenção: chaves são únicas — não pode repetir a mesma chave!
