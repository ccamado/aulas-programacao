Revisão · 07/05
O que já sabemos sobre funções?
# Estrutura básica de uma função def nome_da_funcao(parametro): # corpo da função resultado = parametro * 2 return resultado # Chamando a função x = nome_da_funcao(5) print(x) # 10
📌 Lembra?
  • def cria a função
  • O nome deve ser descritivo
  • return devolve o resultado
  • Sem return, a função devolve None
  • Função só roda quando é chamada
Hoje: vamos adicionar decisões dentro das funções!
Conceito importante
Parâmetro x Argumento — qual a diferença?
📌 Parâmetro — na definição
def dobro(x): return x * 2 # "x" é o PARÂMETRO # é só um nome/espaço reservado
Parâmetro = variável que a função espera receber
🚀 Argumento — na chamada
resultado = dobro(8) print(resultado) # 16 # "8" é o ARGUMENTO # é o valor real passado
Argumento = valor enviado para a função
Resumo: Parâmetro é o "formulário em branco" · Argumento é o "formulário preenchido" 📝
Conteúdo novo
Função desconto() — com decisão
# Função com if/else dentro def desconto(preco): if preco > 100: novo_preco = preco * 0.9 return novo_preco else: return preco # Testando print(desconto(150)) # 135.0 print(desconto(80)) # 80
# Versão mais enxuta def desconto(preco): if preco > 100: return preco * 0.9 return preco # else implícito
📌 Como funciona
  • A função recebe o preço como parâmetro
  • Verifica se o preço é maior que 100
  • Se sim: aplica 10% de desconto e retorna
  • Se não: retorna o preço original
  • Pode ter vários return em ramos diferentes
Importante: quando o Python executa um return, a função termina imediatamente!
Prática individual
Exercício: classificar_idade()
# Crie a função classificar_idade # Regras: # idade < 12 → "Criança" # idade < 18 → "Adolescente" # caso contrário → "Adulto" def classificar_idade(idade): if idade < 12: return "Criança" elif idade < 18: return "Adolescente" else: return "Adulto" # Testes — rode e verifique! print(classificar_idade(8)) # Criança print(classificar_idade(15)) # Adolescente print(classificar_idade(25)) # Adulto
✅ Roteiro
  • Digite a função no Trinket
  • Execute e confira os 3 testes
  • Teste com sua própria idade
  • Teste com idade = 12 e 18 — o que acontece?
Desafio: crie também aprovado(nota) que retorna "Aprovado" se nota ≥ 6, "Recuperação" se ≥ 4, e "Reprovado" caso contrário.
