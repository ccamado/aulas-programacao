Introdução à Lógica de Programação

Resumo para organizar o raciocínio antes de transformar uma solução em código.

Ideia central

Como pensar antes de programar

Lógica de programação não é decorar código. É organizar passos para resolver um problema.

Resumo para o caderno: Lógica de programação é a forma de organizar passos para resolver um problema usando o computador. A lógica é o plano. O código é a tradução desse plano.
Parte 1

Algoritmo

Algoritmo é uma sequência de passos para resolver uma tarefa. Antes de programar, podemos escrever o algoritmo em linguagem natural.

Exemplo: calcular média 1. Ler a primeira nota 2. Ler a segunda nota 3. Somar as notas 4. Dividir por 2 5. Mostrar a média
Parte 2

Entrada, processamento e saída

Entrada

Dados informados pelo usuário.

Processamento

Contas, decisões e regras.

Saída

Resultado mostrado ao usuário.

Entrada: nota1, nota2 Processamento: media = (nota1 + nota2) / 2 Saída: mostrar media
Parte 3

Decisão lógica

Uma condição é uma pergunta que o programa responde com verdadeiro ou falso.

Condição: media >= 6 Se for verdadeiro: aprovado. Se for falso: reprovado.
Parte 4

Repetição

A repetição é usada quando uma ação precisa acontecer várias vezes, como ler notas, listar alunos ou somar produtos.

Exemplo em linguagem natural: Para cada nota de uma lista: 1. Verificar se a nota é maior ou igual a 6 2. Se for, contar como aprovada
Parte 5

Teste de mesa

Teste de mesa é simular o algoritmo no papel para verificar se o resultado está correto.

nota1 = 7 nota2 = 5 media = (7 + 5) / 2 media = 12 / 2 media = 6 Resultado: aprovado
Atividade em sala

Monte um algoritmo no caderno

Escolha um caso: 1. Calcular total de uma compra 2. Verificar se um aluno foi aprovado 3. Calcular desconto de uma venda 4. Registrar atendimento em uma oficina Depois identifique: - entrada - processamento - saída - decisão, se houver
