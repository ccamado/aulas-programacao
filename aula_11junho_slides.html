Motivação
Por que separar em arquivos?
❌ Tudo em um arquivo
Difícil achar funções, difícil reutilizar, vira bagunça rápido.
# Um arquivo gigante # funções misturadas com o programa principal # fica difícil revisar e reaproveitar
✅ Separado (organizado)
Funções em um lugar, programa principal em outro.
funcoes.py -> só funções main.py -> só o programa principal Resultado: fica fácil reutilizar e corrigir.

Comandos
Duas formas de importar
Forma 1: importar o módulo
import funcoes print(funcoes.media(7, 9))
Forma 2: importar funções
from funcoes import media, desconto print(media(7, 9)) print(desconto(120))
Dica: o nome do arquivo (funcoes.py) vira o nome do módulo (funcoes).
Exemplo mínimo
funcoes.py e main.py funcionando
funcoes.py
def media(a, b): return (a + b) / 2 def desconto(preco): if preco > 100: return preco * 0.90 return preco
main.py
from funcoes import media, desconto print("Média:", media(7, 9)) print("Final:", desconto(150))
Anti-trava
Erros comuns (e como resolver)
Checklist rápido
  • Os dois arquivos estão na MESMA pasta?
  • Você salvou como funcoes.py (sem espaço/acentos)?
  • No import, o nome bate com o arquivo? (funcoes)
  • Rodou o arquivo certo? (execute main.py)
  • Indentação correta (4 espaços) dentro das funções?
