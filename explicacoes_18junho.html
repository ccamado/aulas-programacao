Biblioteca Padrão:
math e random

Material de apoio para entender melhor os imports, os módulos e as funções usadas na aula.

Começo da conversa

O que é uma biblioteca padrão?

A biblioteca padrão é um conjunto de módulos que já vem com o Python. Você usa esses módulos com import para reaproveitar código pronto, confiável e testado.

import math
import random

Módulo é um arquivo/conjunto de ferramentas. Função é uma ferramenta específica dentro desse módulo, como math.sqrt() ou random.randint().

Importação

Duas formas de importar

Módulo inteiro

Importa o módulo e chama a função com o nome do módulo na frente.

import math

print(math.sqrt(25))

Resultado: 5.0

Apenas o necessário

Importa somente a função que você vai usar e chama direto pelo nome.

from math import sqrt

print(sqrt(25))

Resultado: 5.0

Qual é a diferença prática? Para quem está aprendendo, import math costuma ser mais didático porque a chamada math.sqrt() mostra a origem da função. Já from math import sqrt deixa o código mais curto, mas a origem aparece só no import do início.

Boa prática

Então qual forma usar no começo?

  • Para aprender, prefira import math e use math.sqrt(), math.ceil() e math.floor().
  • Assim fica visível que a função veio do módulo math.
  • Depois que entender bem, você pode usar from math import sqrt para escrever menos.
  • O importante é não misturar muitas formas no mesmo exercício.
import math

print(math.sqrt(25))
print(math.ceil(6.2))
print(math.floor(6.8))

Forma mais curta, para depois: from math import sqrt, ceil, floor permite escrever sqrt(25), mas quem lê precisa olhar o import para saber de onde veio cada função.

Evite from math import * no início dos estudos. Ele importa tudo e pode deixar confuso de onde cada função veio.

math.sqrt()

Calcula a raiz quadrada de um número.

import math

numero = 25
print(math.sqrt(numero))

Resultado: 5.0

math.ceil()

Arredonda para cima, mesmo quando o decimal é pequeno.

import math

nota = 6.2
print(math.ceil(nota))

Resultado: 7

math.floor()

Arredonda para baixo, descartando a parte decimal.

import math

nota = 6.8
print(math.floor(nota))

Resultado: 6

math.pow()

Calcula potência. math.pow(2, 3) significa 2 elevado a 3.

import math

print(math.pow(2, 3))

Resultado: 8.0

random.randint()

Sorteia um número inteiro dentro de um intervalo.

import random

numero = random.randint(1, 10)
print(numero)

O resultado muda a cada execução.

random.choice()

Escolhe um item de uma lista.

import random

nomes = ["Ana", "Bruno", "Carlos", "Duda"]
sorteado = random.choice(nomes)
print(sorteado)

Bom para sorteios, mensagens e escolhas simples.

random.shuffle()

Embaralha a lista original. Use como curiosidade e observe que a ordem muda dentro da própria lista.

import random

nomes = ["Ana", "Bruno", "Carlos", "Duda"]
random.shuffle(nomes)
print(nomes)

Mini-desafio

Junte as ideias da aula: calcular uma raiz, arredondar uma média, sortear um bônus e escolher uma mensagem motivacional.

import math
import random

media = 6.2
bonus = random.randint(1, 10)
mensagens = ["Continue praticando", "Bom trabalho", "Você evoluiu"]

print("Raiz:", math.sqrt(25))
print("Média arredondada:", math.ceil(media))
print("Bônus:", bonus)
print(random.choice(mensagens))

Resumo para copiar

  • Biblioteca padrão = módulos que já vêm com o Python.
  • import math importa o módulo e deixa a origem clara na chamada: math.sqrt().
  • from math import sqrt deixa a chamada mais curta: sqrt(), mas a origem aparece só no import.
  • math ajuda em cálculos; random ajuda em sorteios.
  • Para o primeiro contato, math.sqrt() e random.randint() são mais didáticos.
