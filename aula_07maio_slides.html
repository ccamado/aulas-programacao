Motivação
Por que precisamos de funções?
❌ Sem função — código repetido
# Calcular média 3 vezes... media1 = (7 + 8) / 2 print(media1) media2 = (5 + 9) / 2 print(media2) media3 = (6 + 10) / 2 print(media3) # Repetição! E se a fórmula mudar?
✅ Com função — escreva uma vez, use sempre
# Define uma vez def media(a, b): return (a + b) / 2 # Usa quantas vezes quiser print(media(7, 8)) print(media(5, 9)) print(media(6, 10))
Vantagem: se precisar mudar a fórmula, muda em um só lugar!
Sintaxe
Anatomia de uma função
def saudacao(nome):parâmetro mensagem = "Olá, " + nome return mensagemdevolve o resultado resultado = saudacao("Ana")chamada da função print(resultado)exibe: Olá, Ana
📌 Partes obrigatórias
  • def — palavra-chave que cria a função
  • Nome da função — descritivo, sem espaços
  • Parênteses () — com ou sem parâmetros
  • Dois pontos : — não esqueça!
  • Indentação — 4 espaços no corpo
📌 Regras do nome
  • Letras minúsculas
  • Palavras separadas por _
  • Não pode começar com número
  • Sem acentos ou espaços
  • Exemplo: calcular_media, dobro
Conceito crucial
return vs print — qual a diferença?
🖨️ print — só exibe
def dobro_print(x): print(x * 2) # exibe dobro_print(5) # mostra: 10 # Mas não posso guardar! resultado = dobro_print(5) print(resultado) # None !
⚠️ Problema: o resultado some após exibir, não posso usar depois
↩️ return — devolve o valor
def dobro_return(x): return x * 2 # devolve # Posso guardar e usar! resultado = dobro_return(5) print(resultado) # 10 print(resultado + 3) # 13
✅ Correto: o valor fica disponível para uso posterior
Regra de ouro: use return quando quiser guardar ou usar o resultado. Use print só para exibir ao usuário.
Prática individual
Criando suas primeiras funções
# 1. Função de saudação def saudacao(nome): return "Olá, " + nome + "!" print(saudacao("Ana")) print(saudacao("João"))
# 2. Dobro de um número def dobro(x): return x * 2 print(dobro(5)) # 10 print(dobro(12)) # 24
# 3. Média de dois valores def media(a, b): return (a + b) / 2 resultado = media(7, 9) print(f"Média: {resultado}")
