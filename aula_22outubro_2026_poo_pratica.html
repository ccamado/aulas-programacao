Roteiro da prática

  1. Abra o Trinket Python 3 e crie uma classe Aviso com __init__, titulo, categoria e ativo.
  2. Implemente o método resumo() e o método validar() para impedir título vazio e categoria fora da lista permitida.
  3. Crie três objetos, imprima os resumos e teste um título vazio para observar a validação.
  4. Registre uma captura da saída e descreva a diferença entre atributo e método.

Código, comandos ou modelo de trabalho

class Aviso:
    # Representa um aviso da Central de Avisos.
    def __init__(self, titulo, categoria):
        self.titulo = titulo.strip()
        self.categoria = categoria.strip()
        self.ativo = True

    def validar(self):
        # Duas regras simples de negócio.
        categorias = ["Evento", "Atividade", "Comunicado"]
        return bool(self.titulo) and self.categoria in categorias

    def resumo(self):
        if not self.validar():
            return "Aviso inválido: revise título ou categoria."
        return f"[{self.categoria}] {self.titulo}"

avisos = [
    Aviso("Feira de Ciências", "Evento"),
    Aviso("Entregar relatório", "Atividade"),
    Aviso("  ", "Evento"),
]
for aviso in avisos:
    print(aviso.resumo())
