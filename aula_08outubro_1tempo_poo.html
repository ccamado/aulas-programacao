POO do zero: classe, objeto, atributo e instanciação

1º tempo · 08/10/2026 · 07:00–07:50

Objetivo da aula: entender concretamente a diferença entre classe e objeto, reconhecer atributos e criar objetos a partir de uma classe sem usar herança, polimorfismo ou estruturas complexas.

1. Começando pelo que já conhecemos

Podemos representar um aviso com um dicionário:

aviso = {
    "titulo": "Prova de Programação",
    "data": "20/10/2026",
    "tipo": "prova"
}

Funciona, mas se tivermos vários avisos todos repetem a mesma estrutura. A orientação a objetos permite criar um modelo para esse tipo de elemento.

2. Classe = molde

Uma classe é um modelo usado para criar objetos.

class Aviso:
    pass
Classe = molde
→
Objeto = elemento criado

pass significa apenas que a classe existe, mas ainda não possui conteúdo.

3. Objeto = ocorrência concreta

class Aviso:
    pass

aviso1 = Aviso()
aviso2 = Aviso()

Aviso é a classe. aviso1 e aviso2 são objetos diferentes da mesma classe.

4. Instanciação

O processo de criar um objeto a partir de uma classe recebe o nome de instanciação.

aviso1 = Aviso()
TrechoSignificado
Avisoclasse
Aviso()instanciação
aviso1objeto / instância

5. Atributos = informações do objeto

aviso1.titulo = "Prova de Programação"
aviso1.data = "20/10/2026"
aviso1.tipo = "prova"

print(aviso1.titulo)
print(aviso1.data)
print(aviso1.tipo)

Podemos ler aviso1.titulo como: “o atributo titulo do objeto aviso1”.

6. Objetos diferentes, valores diferentes

aviso2 = Aviso()
aviso2.titulo = "Reunião"
aviso2.data = "22/10/2026"
aviso2.tipo = "reuniao"

A estrutura é a mesma, mas cada objeto guarda seus próprios valores.

Evite a confusão: a classe não é o objeto. Aviso é o modelo; aviso1 e aviso2 são objetos criados a partir dele.

7. Prática guiada

Analise o código:

class Produto:
    pass

produto1 = Produto()
produto1.nome = "Teclado"
produto1.preco = 100

produto2 = Produto()
produto2.nome = "Mouse"
produto2.preco = 50

Responda:

  1. Qual é a classe?
  2. Quais são os objetos?
  3. Quais são os atributos?
  4. Onde ocorre a instanciação?
Confira: classe = Produto; objetos = produto1 e produto2; atributos = nome e preco; instanciação = nas chamadas Produto().

8. Mini-desafio

Crie uma classe Aluno, depois crie dois objetos e atribua a cada um nome, turma e matricula.

Resumo

Classe é o modelo. Objeto é uma ocorrência criada a partir da classe. Instanciação é o ato de criar esse objeto. Atributo é uma informação pertencente ao objeto.
