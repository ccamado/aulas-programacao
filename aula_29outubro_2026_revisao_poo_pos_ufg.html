2. O problema da Central de Avisos

  • Cada aviso tem título, data e tipo.
  • Precisamos representar ocorrências distintas.
  • Qual a diferença entre o molde e um aviso específico?

3. Classe e objeto

  • class Aviso: define um modelo.
  • aviso1 = Aviso(...) cria um objeto.
  • Dois objetos podem ter valores diferentes.

4. Atributos e self

  • self.titulo guarda o título naquele objeto.
  • self.data guarda a data naquele objeto.
  • self refere-se à instância que está sendo inicializada.

5. __init__: iniciar o objeto

  • def __init__(self, titulo, data):
  • self.titulo = titulo
  • self.data = data
  • A inicialização recebe valores e os atribui ao objeto.

6. Leitura e previsão

  • aviso1 = Aviso("Reunião", "30/10")
  • aviso2 = Aviso("Prova", "05/11")
  • print(aviso2.titulo) → qual será a saída?
  • Explique por que aviso1 não muda.

7. Atividade curta de revisão

  • Identifique classe, objetos e dois atributos.
  • Explique o papel de self e de __init__.
  • Corrija: self.titulo = data (quando queria guardar título).

8. Resumo para o caderno

  • Classe define a estrutura; objeto é uma instância.
  • Atributos armazenam informações de cada objeto.
  • __init__ inicializa o objeto; self aponta para a instância.
  • Uma classe pode originar objetos com dados diferentes.
