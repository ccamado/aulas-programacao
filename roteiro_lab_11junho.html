Criar o arquivo funcoes.py

Objetivo: colocar as funções em um arquivo separado para reaproveitar em outros programas.
1

Crie uma pasta no computador: PA_2026_11-06

2

Crie um arquivo chamado funcoes.py dentro da pasta

3

Copie o código abaixo em funcoes.py e salve

# funcoes.py def media(a, b): return (a + b) / 2 def desconto(preco): if preco > 100: return preco * 0.90 else: return preco * 0.95 def classificar_idade(idade): if idade >= 18: return "Maior" else: return "Menor"
⚡ Desafio (opcional)

Crie mais uma função em funcoes.py: triplo(x) que retorna x * 3.

2
Criar o arquivo main.py e importar
⏱ estimativa: 35 minutos
Objetivo: usar from ... import ... para chamar funções de outro arquivo.
1

Crie um arquivo chamado main.py na mesma pasta

2

Copie e rode este código (execute main.py)

# main.py from funcoes import media, desconto, classificar_idade nome = input("Nome: ") idade = int(input("Idade: ")) print("Olá,", nome) print("Classificação:", classificar_idade(idade)) n1 = float(input("Nota 1: ")) n2 = float(input("Nota 2: ")) print("Média:", media(n1, n2)) preco = float(input("Preço: R$ ")) print("Preço final:", desconto(preco))
✅ O que deve acontecer

O programa pede entradas e imprime a classificação da idade, a média e o preço final com desconto.

⚡ Desafio

Troque o import para import funcoes e use: funcoes.media(...), funcoes.desconto(...) e funcoes.classificar_idade(...).
