POO do zero: self e __init__

2º tempo · 08/10/2026 · 07:50–08:40

Objetivo da aula: entender por que usamos __init__, o que self representa e como os valores recebidos na criação do objeto passam a ser guardados em seus atributos.

1. O problema da forma anterior

aviso1 = Aviso()
aviso1.titulo = "Prova"
aviso1.data = "20/10/2026"
aviso1.tipo = "prova"

Funciona, mas precisamos criar o objeto e depois preencher cada atributo. Também podemos esquecer algum dado.

2. Entrando o __init__

O __init__ é executado quando um novo objeto é criado e serve para inicializar seus dados.

class Aviso:
    def __init__(self):
        print("Um aviso foi criado")

aviso1 = Aviso()

Ao executar Aviso(), o Python cria o objeto e chama o __init__ automaticamente.

3. Recebendo os dados na criação

class Aviso:
    def __init__(self, titulo, data, tipo):
        self.titulo = titulo
        self.data = data
        self.tipo = tipo

Agora podemos criar o objeto já informando seus valores:

aviso1 = Aviso(
    "Prova de Programação",
    "20/10/2026",
    "prova"
)

4. O que é self?

self representa o próprio objeto que está sendo inicializado ou utilizado.

1
Criamos aviso1 = Aviso(...).
2
Durante essa inicialização, self representa aviso1.
3
self.titulo = titulo guarda o valor recebido dentro daquele objeto.

5. A linha mais importante

self.titulo = titulo

À direita, titulo é o valor recebido pelo parâmetro. À esquerda, self.titulo é o atributo que ficará armazenado no objeto.

Importante: você não escreve self ao criar o objeto. Em Aviso("Prova", "20/10/2026", "prova"), o Python fornece a referência ao objeto automaticamente.

6. Objetos diferentes mantêm seus próprios valores

aviso1 = Aviso("Prova", "20/10/2026", "prova")
aviso2 = Aviso("Reunião", "22/10/2026", "reuniao")

print(aviso1.titulo)  # Prova
print(aviso2.titulo)  # Reunião

7. Leia o código em português

class Aviso:
    def __init__(self, titulo, data, tipo):
        self.titulo = titulo
        self.data = data
        self.tipo = tipo
“Estou criando uma classe chamada Aviso. Quando um objeto for criado, ele receberá título, data e tipo. Esses valores serão guardados nos atributos desse próprio objeto.”

8. Prática

Complete:

class Livro:
    def __init__(____, titulo, autor):
        ____.titulo = titulo
        ____.autor = autor

livro1 = Livro("Dom Casmurro", "Machado de Assis")

Depois responda: qual é a classe? qual é o objeto? quais são os atributos? qual é o papel de self? para que serve o __init__?

Resposta: preencher os três espaços com self. Classe = Livro; objeto = livro1; atributos = titulo e autor; self representa o próprio objeto; __init__ inicializa seus dados.

9. Código-base para guardar

class Aviso:
    def __init__(self, titulo, data, tipo):
        self.titulo = titulo
        self.data = data
        self.tipo = tipo

aviso1 = Aviso("Prova", "20/10/2026", "prova")

Resumo

__init__ inicializa o objeto. self representa o próprio objeto. self.atributo = valor guarda um valor dentro desse objeto. Cada instância mantém seus próprios dados.
