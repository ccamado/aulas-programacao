SELECT: como consultar avisos que continuam salvos?

CEPEF · 3º A · Programação Aplicada II · 05/11/2026 · 2º tempo 07h50–08h40 · Prof. Claudio Amado

1. Situação-problema (5 min)

Um aviso foi cadastrado ontem. Hoje abrimos o Python novamente. Uma lista comum de Python teria perdido seus dados ao fechar o processo. Já o registro persistido corretamente no banco pode ser recuperado com uma consulta.

INSERT solicita um novo registro; SELECT recupera dados existentes. O foco hoje é a consulta, não instalar serviços.

3. Leitura de código passo a passo (8 min)

# Exemplo didático: supõe cliente e tabela configurados.
resposta = supabase.table("avisos").select("*").execute()
# Em caso de sucesso, data contém os registros retornados.
avisos = resposta.data
# Exibir o título de cada registro retornado.
for aviso in avisos:
    print(aviso["titulo"])

table("avisos") identifica a tabela; select("*") pede todas as colunas; execute() envia a consulta; resposta.data contém os registros retornados em resposta bem-sucedida. O comando não garante uma ordem sem uma ordenação explícita.

4. Duas respostas diferentes (9 min)

Consulta sem linhas: se a operação concluiu com sucesso e resposta.data = [], nenhum registro foi retornado. Pode depender de filtros e regras de acesso.

Falha na consulta: rede ou permissão podem impedir a execução. Uma falha não é equivalente à lista vazia.

5. Atividade em duplas e análise individual (17 min)

  1. Identifique qual operação cria e qual consulta: INSERT e SELECT.
  2. Copie as três linhas fictícias e escreva os títulos retornados. Uma consulta sem order() não garante a ordem.
  3. Explique o que significa resposta.data = [] quando não houve erro.
  4. Uma falha de permissão deve ser anotada como lista vazia? Justifique.
  5. Como o programa volta a encontrar avisos após reiniciar o Python?
  6. O que faria .select("titulo,data") de diferente de .select("*")?

6. Resumo para o caderno (4 min)

INSERT: solicita inserir registro. SELECT: consulta dados existentes. Consulta Python: supabase.table("avisos").select("*").execute(). Resposta: resposta.data reúne os registros retornados. Resultado vazio não significa necessariamente erro. Persistência significa que dados permanecem no banco após o programa encerrar.
