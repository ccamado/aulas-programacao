Resumo para o caderno

CENTRAL DE AVISOS v0.1

  • Dicionário → representa um aviso.
  • Lista → guarda vários avisos.
  • append() → adiciona um aviso à lista.
  • Função → organiza uma ação do sistema.
  • for → percorre os avisos cadastrados.
  • if/elif/else → escolhe qual ação executar.
  • while → mantém o menu funcionando até o usuário escolher sair.

A Central v0.1 permite:
1 - Cadastrar
2 - Listar
0 - Sair
