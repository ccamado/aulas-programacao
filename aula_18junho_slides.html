Conceito
O que é a biblioteca padrão?
Standard library é um conjunto de módulos que já vem com o Python. Você usa com import para reaproveitar código pronto e confiável.
import math import random
Hoje: vamos usar só o básico de math e random, sem complicar.
Módulo 1
Usando math
import math n = float(input("Digite um número: ")) print("Raiz quadrada:", math.sqrt(n))
Dica
  • math.sqrt(x) calcula a raiz quadrada
  • Se der erro, confira se você fez import math
Módulo 2
Usando random
import random # sorteio de 1 a 10 bonus = random.randint(1, 10) print("Bônus sorteado:", bonus)
Dica
  • random.randint(a,b) sorteia inteiro entre a e b
  • Use para criar jogos simples e motivação
