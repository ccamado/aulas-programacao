Revisão 1

Anatomia de uma função

def dobro(numero): resultado = numero * 2 return resultado print(dobro(6))

Na definição

  • def inicia a função
  • numero é o parâmetro
  • return devolve o resultado

Na chamada

  • dobro(6) chama a função
  • 6 é o argumento
  • A saída será 12
Ponto importante

return não é print

return devolve

def dobro(x): return x * 2 valor = dobro(5) print(valor + 1)
O programa reutiliza o valor 10.

print mostra

def dobro(x): print(x * 2) dobro(5)
print apenas mostra 10.
Revisão 2

Função com if/else

def classificar_nota(nota): if nota >= 6: return "Aprovado" else: return "Recuperação" nota_aluno = float(input("Nota: ")) print(classificar_nota(nota_aluno))

notas = [] notas.append(7.0) notas.append(5.5) notas.append(8.0) print("Notas:", notas) print("Quantidade:", len(notas)) print("Média:", sum(notas) / len(notas)) print("Maior:", max(notas))
