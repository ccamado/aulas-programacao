Central de Avisos: cadastro funcionando

Programação Aplicada II · 3º A · 07:00–07:50

💻 Código inicial ▶ Abrir Trinket ← Voltar
1

Abra o código inicial

Copie o código inicial para o Trinket e execute antes de alterar qualquer coisa.

  • Teste a opção 1.
  • Teste uma opção inválida.
  • Teste a opção 0.
Observe: o menu já funciona, mas a opção 1 apenas mostra uma mensagem. Esse é o problema que vamos resolver.
2

Crie a função de cadastro

Antes do while, crie uma função chamada cadastrar_aviso().

def cadastrar_aviso(): print("\n--- CADASTRO DE AVISO ---")
Não coloque a função dentro do while. Primeiro definimos a ação; depois o menu chama essa ação.
3

Leia os dados do aviso

Dentro da função, peça três informações ao usuário.

titulo = input("Título: ") data = input("Data: ") tipo = input("Tipo: ")
Teste rápido: use “Prova de Programação”, “03/09/2026” e “prova”.
4

Monte um dicionário

Use as variáveis lidas para representar um único aviso.

aviso = { "titulo": titulo, "data": data, "tipo": tipo }
Pense: o dicionário representa um aviso. A lista avisos servirá para guardar vários.
5

Guarde na lista

Depois de montar o dicionário, adicione-o à lista.

avisos.append(aviso) print("Aviso cadastrado com sucesso!")
Diagnóstico: coloque temporariamente print(avisos), cadastre dois avisos e confirme se aparecem dois dicionários na lista.
6

Conecte o cadastro ao menu

Substitua a mensagem provisória da opção 1 por uma chamada da função.

if opcao == "1": cadastrar_aviso()
Atenção: os parênteses em cadastrar_aviso() indicam que a função será executada.
