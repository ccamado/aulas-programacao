PA II — CRUD: UPDATE e DELETE

CEPEF • 3º A — Programação Aplicada II • 12/11/2026

Objetivo

Compreender CRUD e interpretar UPDATE/DELETE em Python + Supabase.

CRUD

  • Create: cadastrar
  • Read: consultar
  • Update: alterar
  • Delete: excluir

UPDATE

supabase.table("avisos").update({"titulo":"Prova adiada"}).eq("id",2).execute()

O filtro eq identifica o alvo. Depois, consulte novamente para validar.

DELETE

supabase.table("avisos").delete().eq("id",4).execute()

Fluxo seguro: listar → identificar → confirmar → executar → consultar → validar.
